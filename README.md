# Telegram Digital Shop Bot

Этот проект представляет собой телеграм-бота для магазина цифровых товаров. Бот позволяет пользователям просматривать каталог товаров, а также осуществлять покупки. Администраторы могут управлять товарами через админ-панель.

## Структура проекта

```
telegram-digital-shop-bot
├── src
│   ├── bot.py               # Точка входа для бота
│   ├── admin
│   │   └── panel.py         # Админ-панель для управления товарами
│   ├── catalog
│   │   └── products.py      # Управление каталогом товаров
│   ├── purchase
│   │   └── buy.py           # Процесс покупки товаров
│   ├── database
│   │   └── models.py        # Модели базы данных
│   └── utils
│       └── helpers.py       # Вспомогательные функции
├── requirements.txt          # Зависимости проекта
└── README.md                 # Документация проекта
```

## Установка

1. Клонируйте репозиторий:
   ```
   git clone <URL>
   cd telegram-digital-shop-bot
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Использование

1. Запустите бота:
   ```
   python src/bot.py
   ```

2. Следуйте инструкциям в чате с ботом для взаимодействия с каталогом и покупками.
